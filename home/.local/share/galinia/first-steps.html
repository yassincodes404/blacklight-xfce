Welcome home.

This guide is available offline. Galinia is a desktop profile built on Ubuntu / Xubuntu. This preview targets XFCE on X11; hardware and clean-install qualification remain in progress.

First steps · Shortcuts · Updates & backups · Recovery

Start comfortably

  • Open Settings to set display resolution, scaling, keyboard layout and accessibility preferences.
  • Use Desktop Settings to select a wallpaper. Galinia adapts its accent colors to it.
  • Use the panel’s network and audio controls. Open Bluetooth Manager to pair devices.
  • Open Software to find applications. Galinia includes Firefox, Thunar, Mousepad, a calculator, gThumb, Celluloid and Amberol in its baseline package list.
  • Open Welcome to Galinia from app search whenever you need the setup shortcuts again.

A few useful shortcuts

  • Super + Space: search applications.
  • Super + S: open settings.
  • Super + E: open files.
  • Ctrl + Alt + T: open a terminal.
  • Super + L: lock the screen. Verify locking works before relying on it.
  • Print Screen or Super + Shift + S: select a screenshot region. It saves to Pictures/Screenshots and copies automatically; use Ctrl + V to paste into an app that accepts images. Escape cancels.
  • Alt + Tab: switch windows.

Keep your work safe

Use Software Updater for upstream package and security updates. Restart when requested. Use Software & Updates → Additional Drivers to review available hardware drivers. These operations may require internet access and administrator authentication.

Use Backups (Déjà Dup) to back up personal files to another drive or location. Test that you can restore a file. A Galinia configuration backup does not back up your documents.

The script preview does not automatically update Galinia’s own profile. Review release instructions before applying a newer profile. Optional browser policies and boot branding are not applied by this installer.

If something goes wrong

Try logging out and selecting the Xfce Session on X11 at login. The preview installer refuses to change settings while XFCE is running.

For configuration restore, log out completely, switch to a text console with Ctrl + Alt + F3, and log in as the same user. From your Galinia repository, run python3 tools/install.py restore RESTORE_ID. Use the restore ID printed by installation; journals are kept in ~/.local/state/galinia/installs/. Restore the newest installation first.

Restore preserves installed packages and refuses to overwrite files edited after installation. Use python3 tools/install.py restore RESTORE_ID --save-conflicts to save later edits alongside the backup before restoring. The command prints where those files were preserved. An interrupted installation can be restored using the same journal. Empty directories and generated runtime caches may remain.

If the computer cannot boot, use your Ubuntu/Xubuntu recovery or live media. The profile installer does not modify the bootloader, partitioning, authentication, or initramfs.
